      Semester project – úplné původní zadání

      Termín: pondělí, 7. prosince 2026, 23.55 (Europe/Prague)

      Zdroj v Moodle

      Create your own website that will represent your interests, hobbies, or your own creative or business activity. Use Bootstrap framework components to create a responsive website.

      Part of the semester project will be the creation of a wireframe of the homepage of the website when viewed on a mobile device (a typical smartphone). Briefly describe elements of the wireframe (website structure).

      Also, you need to upload the semester project to a hosting service of your choice (free hosting, your own hosting, GitHub Pages, etc.) and create a TXT file containing the project URL, which must be included in the submitted ZIP file.

      The website will contain the following components:

      • logo, or an appropriately styled text name of the project at the top of the page
      • 5 - 7 menu items referring to individual functional pages with real content (text, possibly also visual)
      • appropriate use and placement (preferably under the logo and menu, otherwise preferably at the top of the page) of the Carousel component with the display of several rotating images, possibly together with a text message displayed over these images - Docs - Components - Carousel
      • breadcrumb navigation, e.g. Introduction - About us, etc.
      • own comprehensive form - see below
      • a table with at least 50 records created based on the DataTable component - https://datatables.net/examples/styling/bootstrap5.html (adapted for Bootstrap version 5) along with pagination, sorting and searching
      • several links and buttons using different styles - section Docs - Components - Buttons, use of icons in menu items or buttons - Docs - Extend - Icons

      • modal window with the display of detailed information of any type - Docs - Components - Modal

      • at least 3 tabs with any content and displaying tab content on click - Docs - Components - Navs & tabs
        any other components or components that you use to create the website

      A comprehensive responsive form will include:

      • the form will have a total of at least 10 form fields
      • use a form field at least once in the form: text type input, radio type input, checkbox type input, selection of values ​​using the select element (values ​​in option elements), textarea
      • Save button at the bottom of the form
      • use the tips and layout of form fields available in the Forms and Forms - Input Group sections

      The resulting web page, TXT file with URL od project online, together with other necessary files zip into a ZIP file and submit

      Task 1 – úplné původní zadání

      Termín: středa, 21. října 2026, 23.59 (Europe/Prague)

      Zdroj v Moodle

      Create 3 wireframes in Figma tool (https://www.figma.com/) for the product detail - for PC, tablet and mobile phone

      The output is a total of 3 wireframes!

      Wireframe contains:

      • on the left - name, photo and description
      • on the right - price excluding VAT, price including VAT, product code, add to cart button
      • under the photo - tabs:
        Parameters - dimensions, operating system, internal memory, camera resolution, display type, Wi-Fi, Color
        Reviews - list of reviews for the product, author, text, number of stars
        Related products - list of related products - e.g. headphones, hands-free kit, cover, charger, etc.

      Insert real texts into wireframes for product detail. 

      Export wireframes to PDF and upload them here.

      Task 2 – úplné původní zadání

      Termín: sobota, 21. listopadu 2026, 23.59 (Europe/Prague)

      Zdroj v Moodle

      Download the Bootstrap framework (https://getbootstrap.com/docs/5.3/getting-started/download/) and create a new page called detail.html

      In the detail.html file, create an article detail as follows:

      • The grid system will be divided into 8 columns for the article detail and 4 columns for the More Articles section
      • The article detail will be on the left, the More Articles section on the right - the layout using a wireframe is here: https://wireframe.cc/qRS50Q and below in the document
      • At the top will be the level 1 heading - the article title
      • Below the heading will be the date - suitably styled - choose a Badge
      • Below the date will be a centered image of the article (the width of the image will be 50% of the possible display area) use a suitable div of the col class
      • Below the image will be the text of the article (download the full description of the article- https://cs.wikipedia.org/wiki/Vltava) - but display only the first approximately 5 lines of the article text and the rest of the article text will be displayed only after clicking the show more button - use the Collapse functionality for this
      • Next to the article will be the More Articles section - where you will display 3 arbitrary articles below each other - always the title, date, image and the article detail button - individual articles suitably style and separate with horizontal lines

      HTML file with other files (framework Boostrap) upload here as one ZIP file
