SOUHRN KURZU
Kurz pokrývá návrh a tvorbu responzivních webů pro počítače, tablety a telefony.
Základem je mobile-first přístup, viewport, relativní a absolutní jednotky,
flexbox a grid. Další témata zahrnují optimalizaci CSS a obrázků, CDN,
frameworky a praktické používání Bootstrapu.

Šest tematických prezentací:
1. Úvod: webové stránky, mobilní zařízení, principy responzivního návrhu,
   relativní/absolutní jednotky a specifikace viewportu.
2. Struktura: mobile-first, mobilní verze versus responzivní web,
   struktura webu, optimalizace CSS a obrázků, CDN.
3. Frameworky: výhody frameworků; Bootstrap, Foundation, Bulma,
   Materialize, UIKit, PureCSS a Miligram (takto pojmenováno v osnově).
4. Flexbox a grid: vlastnosti rodičovských a dětských prvků,
   flex-wrap a flex-direction.
5. Bootstrap I: media queries, specifikace Level 4, breakpointy,
   navbar, pills, tabs a šablony.
6. Bootstrap II: obrázky, embed, carousel, ikony a FontAwesome.

Basic information dále uvádí návrh wireframů, responzivní navigaci a formuláře,
modální okna, tabulky, DataTable (řazení, filtrování, stránkování), strukturu
webu s články a novinkami, práci podle šablony, záložky, multimediální obsah
a návrh i realizaci vlastního komplexního responzivního webu.
Úplné původní anglické znění: export/basic-information.txt.

TERMÍNY A ZADÁNÍ

Semester project – 7. 12. 2026, 23:55
Vlastní responzivní web o zájmech, koníčcích nebo tvůrčí/podnikatelské činnosti
s komponentami Bootstrapu. Součástí je wireframe hlavní stránky pro smartphone
a stručný popis prvků. Web musí být na hostingu; do odevzdávaného ZIPu patří
také TXT soubor s jeho URL.
Požadované části:
- Logo nebo stylizovaný textový název nahoře.
- 5 až 7 položek menu vedoucích na funkční stránky se skutečným obsahem.
- Carousel s více obrázky, nejlépe pod logem a menu nebo v horní části stránky.
- Drobečková navigace.
- Responzivní formulář s nejméně 10 poli; alespoň jednou textový input,
  radio, checkbox, select s option a textarea; tlačítko Save dole.
  Využít doporučení Forms a Forms – Input Group.
- DataTable pro Bootstrap 5 s nejméně 50 záznamy, stránkováním, řazením
  a vyhledáváním.
- Odkazy a tlačítka s různými styly; ikony v menu nebo tlačítkách.
- Modální okno s podrobnými informacemi.
- Nejméně 3 záložky s obsahem přepínaným kliknutím.
Odevzdání: ZIP s webem, potřebnými soubory a TXT s URL; zahrnout také wireframe.
Původní úplné zadání: export/semester-project.txt a kurz.html.

Task 1 – 21. 10. 2026, 23:59
Sekce je výslovně určená pouze studentům XREWB a 2REWB.
Ve Figmě vytvořit 3 wireframy detailu produktu: PC, tablet a mobil.
Vlevo název, fotografie a popis; vpravo ceny bez/s DPH, kód produktu
a tlačítko přidání do košíku. Pod fotografií záložky Parameters (rozměry,
operační systém, paměť, fotoaparát, displej, Wi-Fi, barva), Reviews
(autor, text, hvězdičky) a Related products. Použít skutečné texty.
Odevzdání: export wireframů do PDF.
Původní úplné zadání: export/task-1.txt a kurz.html.

Task 2 – 21. 11. 2026, 23:59

na stránce nebyl; dostupný je pouze odkaz https://wireframe.cc/qRS50Q.
